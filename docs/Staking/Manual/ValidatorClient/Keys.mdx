## :moneybag: Preparing Funds

If you are creating a staking node on Hoodi testnet, then you must stake Hoodi ETH (hETH). If you are creating a staking node on Mainnet, then you must stake ETH

For each staking node that you operate, you must stake at least 32 (h)ETH

Send all funds that you plan to stake to the same wallet address. Use [Rabby Wallet](https://rabby.io/) or [MetaMask](https://metamask.io/), for example.

## :money_with_wings: Selecting a Withdrawal Address

Ethereum sends automatic or manually requested staking [withdrawals](https://notes.ethereum.org/@launchpad/withdrawals-faq#Q-What-are-the-two-types-of-withdrawals) to the withdrawal address that you designate.

Use a separate wallet address for withdrawals. The withdrawal address that you set is permanent. Therefore, verify the withdrawal address carefully.

<table class="box">
  <tbody>
    <tr>
      <td class="boxLabel"><p class="boxLabel">Important<br /><img src={useBaseUrl('img/BoxImportant.png')} alt="Important" /></p></td>
      <td class="boxText"><p class="boxText">Do NOT use a wallet address on a centralized exchange for withdrawals.</p></td>
    </tr>
  </tbody>
</table>

If you are creating a staking node on Hoodi testnet, then you can use a hot wallet address for withdrawals. Alternately, use a multi-signature wallet such as [Protofire Safe](https://app.safe.protofire.io/welcome).

If you are creating a staking node on Mainnet, then use a hardware wallet address for withdrawals, or use a multi-signature wallet such as [Safe&#123;Wallet&#125;](https://safe.global/)

Your withdrawal address must be in checksum format, which mixes lowercase and uppercase letters. To validate the address format, use a block explorer such as [Etherscan](https://etherscan.io).

## :key: Generating Validator Keys

If you are creating a staking node on Hoodi testnet:

1. Download the software that you need to generate the 24-word mnemonic seed to the local computer.
2. Physically disconnect the computer from the Internet.
3. Generate the mnemonic seed.

If you are creating a staking node on Mainnet, for increased security:

1. Download the software that you need to generate the 24-word mnemonic seed to a USB stick.
2. Physically disconnect the computer from the Internet.
3. Start your computer using a bootable USB stick to load the operating system.
4. Generate the mnemonic seed using the USB stick that you created in step 1

  <summary>Option 1 - `ethstaker-deposit-cli` Using Ubuntu</summary>

  [ethstaker-deposit-cli](https://github.com/ethstaker/ethstaker-deposit-cli) is a tool for creating keystores and other files required to make staking deposits for an Ethereum validator.

  <p class="pi">To generate validator keys using `ethstaker-deposit-cli` on Ubuntu:</p>

  <ol>
    <li>Using a terminal window, type the following commands to download `ethstaker-deposit-cli` from GitHub:</li>

```bash
# Install dependencies
sudo apt install jq curl -y

# Define variables
RELEASE_URL="https://api.github.com/repos/ethstaker/ethstaker-deposit-cli/releases/latest"
BINARY_URL="$(curl -s $RELEASE_URL | jq -r ".assets[] | .browser_download_url" | grep linux-amd64.tar.gz$)"
BINARY_FILE="ethstaker-deposit-cli.tar.gz"

echo "Downloading URL: $BINARY_URL"

cd $HOME
# Download the archive
wget -O $BINARY_FILE $BINARY_URL
# Extract the archive
tar -xzvf $BINARY_FILE
# Rename the extracted folder
mv ethstaker_deposit*amd64 ethstaker-deposit-cli
# Navigate to the extracted folder
cd ethstaker-deposit-cli
```

    <li>To create a new mnemonic, type the following command where `<NetworkName>` is the value `hoodi` if you are creating a node on Hoodi testnet, or `mainnet` if you are creating a node on Mainnet; and, `<WithdrawalAddress>` is your withdrawal address:</li>

```bash
./deposit new-mnemonic --chain <NetworkName> --execution_address <WithdrawalAddress>
```

    <li>Follow the prompts on screen.</li>

  </ol>

<details>

  <summary>Option 2 - WAGYU Using Linux, Windows or MacOS</summary>

  To simplify creating Ethereum validator keys, [WAGYU](https://wagyu.gg/) uses a graphical user interface (GUI).

  **To generate validator keys using WAGYU:**

  1. Using a Web browser, navigate to https://wagyu.gg/ then download WAGYU for your operating system, and then install WAGYU as may be needed.
  2. Run WAGYU, and then click the **Create New Secret Recovery Phrase** button.
  3. In the **Network** dialog, select the Ethereum network where you are creating one or more staking nodes, and then click **OK**
  4. Click the **Create** button.
  5. Write down the 24-word secret recovery phrase, then click **Next**, and then click **I'm Sure**
  6. Retype the secret recovery phrase, and then click **Check**
  7. In the **Ethereum Withdrawal Address** field, paste your withdrawal address.
  8. In the **Deposit Amount** field, type the total number of hETH or ETH to stake.
  9. If you want to create one or more compounding validators, then select the **Compounding Credentials (0x02)** checkbox.
  10. In the **Number of New Keys** field, type how many staking nodes you want to create.
  11. In the **Password** field, type a password to secure the validator keystore(s), and then click **Next**
  12. When prompted, retype the keystore password, and then click **Next**
  13. Click the **Browse** button, then navigate to the folder where you want to save the new validator keys, then click **Select Folder**, and then click **Create**
  14. When WAGYU finishes creating the keystore and deposit data file(s), click the **Close** button.

</details>

**To create the destination folder for the validator key files:**

<ul class="ss">
  <li>On the computer where you are creating a staking node, type the following command using a terminal window:</li>

```bash
mkdir -p $HOME/ethstaker-deposit-cli/validator_keys
```

</ul>

To transfer validator key files to your node, consider the following options.

<details>

  <summary>Option 2 - USB Stick</summary>

  **To copy validator keys from an offline computer to a USB stick:**

  <ol>

    <li>Connect the USB stick to the offline computer, and then type the following commands using a terminal window to mount the USB stick, where `<DevicePath>` is the path to the partition on the USB stick that the `fdisk` command displays:</li>

```bash
# Locate the USB stick
sudo fdisk -l
# Create a mount point
sudo mkdir -p /media/usb-drive
# Mount the USB stick
sudo mount <DevicePath> /media/usb-drive
```

    <li>To copy the validator keys from the offline computer to the USB stick, type:</li>

```bash
# Create a directory on the USB stick for storing the validator key files
sudo mkdir -p /media/usb-drive/ethstaker-deposit-cli/validator_keys
# Copy the validator keys to the USB stick
sudo cp $HOME/ethstaker-deposit-cli/validator_keys/*.json /media/usb-drive/ethstaker-deposit-cli/validator_keys
# Safely disconnect the USB stick from the computer
sudo umount /media/usb-drive
```

  </ol>

  **To copy validator keys from the USB stick to the staking node:**

  <ol>
    <li>Connect the USB stick to the computer where you are creating a staking node, and then type the following commands using a terminal window to mount the USB stick, where `<DevicePath>` is the path to the partition on the USB stick that the `fdisk` command displays:</li>

```bash
# Locate the USB stick
sudo fdisk -l
# Create a mount point
sudo mkdir -p /media/usb-drive
# Mount the USB stick
sudo mount <DevicePath> /media/usb-drive
```

   <li>To copy the validator keys from the USB stick to the staking node, type:</li>

```bash
# Create a directory on the staking node for storing the validator key files
sudo mkdir -p $HOME/ethstaker-deposit-cli/validator_keys
# Copy the validator keys to the staking node
sudo cp /media/usb-drive/ethstaker-deposit-cli/validator_keys/*.json $HOME/ethstaker-deposit-cli/validator_keys
# Safely disconnect the USB stick from the computer
sudo umount /media/usb-drive
```

  </ol>

</details>

**To verify that files appear in the correct location:**

<ul class="ss">
  <li>On the computer where you are creating a staking node, type the following command using a terminal window:</li>

## :pencil2: Creating Backups

To create backups of critical staking node data:

* **Stay Offline**—Store the 24-word mnemonic seed for the staking node(s) that you operate offline, for example using a [metal seed storage device](https://jlopp.github.io/metal-bitcoin-storage-reviews/). Do **not** use e-mail or the cloud.
* **Hardware Wallet**—Back up the mnemonic for the hardware wallet controlling the ETH that you stake and the withdrawal address that you set.
* Using a USB stick, store copies of:
  * **`validator_keys`**—The directory containing the Keystore and Deposit Data JSON files
  * **Keystore Password**—Required to decrypt Keystore files
* **Multiple Backups**—Store a copy of backups in multiple locations.

Verifying annually that critical staking node data is backed up and accessible is good practice.
