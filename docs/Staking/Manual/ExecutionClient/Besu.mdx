## Overview

Hyperledger Besu is an open-source Ethereum client designed for demanding enterprise applications requiring secure, high-performance transaction processing in a private network. Besu is developed under the Apache 2.0 license and written in [Java](https://www.java.com).

For more details, see:

* **Web Site**—[LF Decentralized Trust](https://www.lfdecentralizedtrust.org/projects/besu)
* **Documentation**—[Besu Ethereum Client](https://docs.besu-eth.org/)
* **Releases**—[GitHub](https://github.com/besu-eth/besu/releases)

## 1. Initial Configuration

To create a user for the execution service, create a data directory and assign ownership, type:

```bash
sudo adduser --system --no-create-home --group execution
sudo mkdir -p /var/lib/besu
sudo chown -R execution:execution /var/lib/besu
```

To install dependencies, type:

```bash
sudo apt install -y openjdk-21-jdk libjemalloc-dev jq
```

## 2. Install Binaries

While downloading binaries is often faster and more convenient, building from source code can offer better compatibility and is more aligned with the spirit of free open source software (FOSS).

<details>

<summary>Option 1 - Downloading Binaries</summary>

To download the latest Besu release for Linux, extract the archive and clean up, type the following commands:

```bash
RELEASE_URL="https://api.github.com/repos/besu-eth/besu/releases/latest"
TAG=$(curl -s ${RELEASE_URL} | jq -r .tag_name)
BINARIES_URL="https://github.com/besu-eth/besu/releases/download/${TAG}/besu-${TAG}.tar.gz"

echo Downloading URL: ${BINARIES_URL}

cd ${HOME}
wget -O besu.tar.gz ${BINARIES_URL}
tar -xzvf besu.tar.gz -C ${HOME}
rm besu.tar.gz
sudo mv ${HOME}/besu-${TAG} besu
```

To install the binaries, type:

```bash
sudo mv ${HOME}/besu /usr/local/bin/besu
```

</details>

<details>

<summary>Option 2 - Compiling Source Code</summary>

To build the binaries, type:

```bash
mkdir -p ~/git
cd ~/git
# Clone the repo
git clone https://github.com/besu-eth/besu.git
cd besu
# Get new tags
git fetch --tags
# Get latest tag name
latestTag=$(git describe --tags `git rev-list --tags --max-count=1`)
# Checkout latest tag
git checkout ${latestTag}
# Build
./gradlew installDist
```

To verify that Besu compiled successfully, type the following command to display the version:

```shell
./build/install/besu/bin/besu --version
```

The `besu --version` command displays output similar to the following:

```
besu/v23.4.0/linux-x86_64/openjdk-java-17
```

To install the binaries, type:

```bash
sudo cp -a $HOME/git/besu/build/install/besu /usr/local/bin/besu
```

</details>

## 3. Set Up and Configure Automatic Startup

To configure a service, create a systemd unit file named `execution.service`

```bash
sudo nano /etc/systemd/system/execution.service
```

In the `execution.service` file, paste the following lines where `<NetworkName>` is the value `hoodi` if you are creating a node on Hoodi testnet, or `mainnet` if you are creating a node on Mainnet.

```shell
[Unit]
Description=Besu Execution Layer Client Service
Wants=network-online.target
After=network-online.target
Documentation=https://ethpillar.coincashew.io/

[Service]
Type=simple
User=execution
Group=execution
Restart=on-failure
RestartSec=3
KillSignal=SIGINT
TimeoutStopSec=900
Environment="JAVA_OPTS=-Xmx5g"
ExecStart=/usr/local/bin/besu/bin/besu \
  --network=<NetworkName> \
  --p2p-port=30303 \
  --rpc-http-port=8545 \
  --engine-rpc-port=8551 \
  --max-peers=25 \
  --metrics-enabled=true \
  --metrics-port=6060 \
  --rpc-http-enabled=true \
  --sync-mode=SNAP \
  --data-storage-format=BONSAI \
  --data-path="/var/lib/besu" \
  --engine-jwt-secret=/secrets/jwtsecret
  
[Install]
WantedBy=multi-user.target
```

To save and exit nano, press `CTRL+X`, then press `Y`, and then press `ENTER`

To enable the service to start automatically when the computer boots, type the following commands:

```bash
sudo systemctl daemon-reload
sudo systemctl enable execution.service
```

Lastly, start your execution layer client and check the status.

```bash
sudo systemctl start execution.service
sudo systemctl status execution.service
```

To exit the status display, press `CTRL+C`

## 4. Helpful Execution Client Commands

<Tabs>
<TabItem value="x" label="View Logs" >
```bash
sudo journalctl -fu execution.service | ccze
```

A properly functioning Besu execution client includes `fork-choice-update` entries in logs. For example:

```
2022-03-19 04:09:36.315+00:00 | vert.x-worker-thread-0 | INFO  | EngineForkchoiceUpdated | Consensus fork-choice-update: head: 0xcd2a_8b32..., finalized: 0xfa22_1142...
2022-03-19 04:09:48.328+00:00 | vert.x-worker-thread-0 | INFO  | EngineForkchoiceUpdated | Consensus fork-choice-update: head: 0xff1a_f12a..., finalized: 0xfa22_1142...
```

:::important
Warnings or errors that logs display normally resolve when both the execution and consensus clients are fully synchronized with the Ethereum network.
:::
</TabItem>

<TabItem value="d" label="Reset Database" >
Common reasons to reset the database include:

* Recovering from a corrupted database due to power outage or hardware failure
* Resynchronizing to reduce disk space usage
* Upgrading to a new storage format

```bash
sudo systemctl stop execution.service
sudo rm -rf /var/lib/besu/*
sudo systemctl restart execution.service
```

The execution client may resychronize for a few hours, up to a day.
