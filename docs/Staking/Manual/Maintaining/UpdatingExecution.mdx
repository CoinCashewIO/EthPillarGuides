## :fast_forward: Updating Manually

When a new execution client release is available, update to the latest stable version.

Prior to updating, always review release notes. Changes may require your attention.

* [Besu](https://github.com/besu-eth/besu/releases)
* [Erigon](https://github.com/erigontech/erigon/releases)
* [Geth](https://github.com/ethereum/go-ethereum/releases)
* [Nethermind](https://github.com/NethermindEth/nethermind/releases)
* [Reth](https://github.com/paradigmxyz/reth/releases)

Follow the procedure for your execution client:

* [Besu](#Besu)
* [Erigon](#Erigon)
* [Geth](#Geth)
* [Nethermind](#Nethermind)
* [Reth](#Reth)

### Besu

<details>

<summary>Option 1 - Downloading Binaries</summary>

To download the latest Linux release, extract the archive and clean up, type:

```bash
RELEASE_URL="https://api.github.com/repos/besu-eth/besu/releases/latest"
TAG=$(curl -s {$RELEASE_URL} | jq -r .tag_name)
BINARIES_URL="https://github.com/hyperledger/besu/releases/download/${TAG}/besu-${TAG}.tar.gz"

echo Downloading URL: ${BINARIES_URL}

cd ${HOME}
wget -O besu.tar.gz ${BINARIES_URL}
tar -xzvf besu.tar.gz -C ${HOME}
rm besu.tar.gz
sudo mv ${HOME}/besu-${TAG} besu
```

To stop the service, type:

```bash
sudo systemctl stop execution.service
```

To remove old binaries, install new binaries and restart the service, type:

```bash
sudo rm -rf /usr/local/bin/besu
sudo mv ${HOME}/besu /usr/local/bin/besu
sudo systemctl start execution.service
```

</details>

<details>

<summary>Option 2 - Compiling Source Code</summary>

To compile binaries, type:

```bash
cd ~/git/besu
# Get new tags
git fetch --tags
# Get latest tag name
latestTag=$(git describe --tags `git rev-list --tags --max-count=1`)
# Checkout latest tag
git checkout $latestTag
# Build
./gradlew installDist
```

To verify that Besu compiled correctly, type:

```shell
./build/install/besu/bin/besu --version
```

The `besu --version` command displays otuput similar to:

```
besu/v23.4.0/linux-x86_64/openjdk-java-17
```

To stop the service, type:

```bash
sudo systemctl stop execution.service
```

To remove old binaries, install new binaries and restart the service, type:

```bash
sudo rm -rf /usr/local/bin/besu
sudo cp -a $HOME/git/besu/build/install/besu /usr/local/bin/besu
sudo systemctl start execution.service
```

</details>

### Geth

<details>

<summary>Option 1 - Downloading Binaries</summary>

To download the latest Linux release, extract the archive and clean up, type:

```bash
RELEASE_URL="https://geth.ethereum.org/downloads"
FILE="https://gethstore.blob.core.windows.net/builds/geth-linux-amd64[a-zA-Z0-9./?=_%:-]*.tar.gz"
BINARIES_URL="$(curl -s ${RELEASE_URL} | grep -Eo ${FILE} | head -1)"

echo Downloading URL: ${BINARIES_URL}

cd $HOME
wget -O geth.tar.gz ${BINARIES_URL}
tar -xzvf geth.tar.gz -C ${HOME} --strip-components=1
```

To stop the service, type:

```bash
sudo systemctl stop execution.service
```

To install new binaries, restart the service and clean up files, type:

```bash
sudo mv ${HOME}/geth /usr/local/bin
sudo systemctl start execution.service
rm geth.tar.gz COPYING
```

</details>

<details>

cd $HOME/git/go-ethereum
# Get new tags
git fetch --tags

### Reth

<details>

<summary>Option 1 - Downloading Binaries</summary>

To download the latest Linux release, extract the archive and clean up, type:

```bash
RELEASE_URL="https://api.github.com/repos/paradigmxyz/reth/releases/latest"
BINARIES_URL="$(curl -s ${RELEASE_URL} | jq -r '.assets[] | select(.name | startswith ("reth")) | .browser_download_url' | grep x86_64-unknown-linux-gnu.tar.gz$)"

echo Downloading URL: ${BINARIES_URL}

cd ${HOME}
wget -O reth.tar.gz ${BINARIES_URL}
tar -xzvf reth.tar.gz -C ${HOME}
rm reth.tar.gz
```

To stop the service, type:

```bash
sudo systemctl stop execution.service
```

To remove old binaries, install new binaries, display the version and restart the service, type:

```bash
sudo rm -rf /usr/local/bin/reth
sudo mv ${HOME}/reth /usr/local/bin
reth --version
sudo systemctl restart execution.service
```

</details>

<details>

<summary>Option 2 - Compiling Source Code</summary>

To compile binaries, type:

```bash
cd ~/git/reth
git fetch --tags
# Get latest tag name
latestTag=$(git describe --tags `git rev-list --tags --max-count=1`)
# Checkout latest tag
git checkout $latestTag
# Build the release
cargo build --release --features jemalloc
```

To verify that Reth compiled successfully, type:

```bash
~/git/reth/target/release/reth --version
```

In case of compilation errors, type:

```bash
rustup update
cargo clean
cargo build --release --features jemalloc
```

To stop the service, type:

```bash
sudo systemctl stop execution.service
```

To remove old binaries, install new binaries and restart the service, type:

```bash
sudo rm -rf /usr/local/bin/reth
sudo cp ~/git/reth/target/release/reth /usr/local/bin
sudo systemctl restart execution.service
```

</details>
